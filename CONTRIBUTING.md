# Contributing to Weasley Frame

Thank you for helping improve an open, verifiable web-research tool.

1. Fork the repository and create a focused branch.
2. Run `make dev` for the supported development environment.
3. Keep backend logic in `backend/`; do not add frontend API routes.
4. Never commit `.env` files, credentials, exports containing private data, or
   generated runtime state.
5. Run `npm test`, `npm run build`, and the relevant authorization checks.
6. Explain user-visible behavior, security impact, and validation in the PR.

By submitting a contribution, you agree that it is licensed under Apache-2.0.
