# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for
`potatohoney-p/weasley-frame`. Include affected versions, reproduction steps,
impact, and any suggested mitigation. Remove API keys, personal data, and live
service credentials from the report.

The maintainers will acknowledge a complete report, investigate it, and publish
a coordinated fix and advisory when appropriate. Supported security fixes target
the latest release and the default branch.
